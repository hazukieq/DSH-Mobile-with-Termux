# 后台进度与悬浮窗

设置 → 后台进度提示 → 显示方式：

| 模式 | 行为 | 依赖 |
|---|---|---|
| 关闭 | 不显示进度 | 不影响其他手机能力 |
| 通知 | 后台原地更新进度，完成后约 2 分钟清除 | 通知权限 |
| 悬浮窗（默认） | 前后台显示状态球/卡片 | 已连接的无障碍服务，或悬浮窗权限 |

切到悬浮窗会立即尝试建窗；没有快照时显示空闲。预览使用当前显示方式；关闭模式下不预览。
无障碍已连接时不要求额外悬浮窗权限。两条授权路径均不可用时，收到进度会提示授权。

## 事件来源

`assets/android-plugins/mobile-progress/index.js` 订阅引擎事件，不抓 WebUI DOM：

- `agent/assistant-stream`：汇总推理、工具和回复；同一 turn 内的多个 attempt 保留前文。
- `session/event`：补充工具调用与结果。
- `agent/status=idle`：强制发出 done；运行中约 2.5 秒心跳。

插件约 250ms 节流，通过带 `X-DSH-Token` 的 `POST /overlay` 推送到 ProgressHub。
普通 `status/action`、`POST /launch` 和 `POST /open` 的动作说明进入独立动作行，正文不被动作行覆盖。
`window.DshNative.a11y(line)` 与兼容名 `notice(text)` 同样追加动作行。

## 显示内容

球为 36dp；点球展开 240dp 宽卡片，点卡片左侧圆点收起。正文滚动区固定 92dp，
空白处可拖动，松手吸附最近的左/右边缘；长按没有隐藏功能。
展开后的形态不随工作状态自动改变。卡片依次显示正文、可选动作行、会话标题与耗时。

| 层 | 文本预算 |
|---|---|
| 插件链路 | 最近 16000 字符 |
| 单个思考块 | 前 1400 字符 |
| 工具行 | 调用状态标签，不展示完整参数 |
| 单个回复 | 最近 4000 字符 |
| ProgressHub | detail 前 16000，think 前 4000 字符 |
| 悬浮窗正文 | 最近 600 字符 |

动作链保留最近 4 条，控件显示最多 2 行；会话标题末尾省略。
正文每次变化自动滚到底部；完整历史在 WebUI 查看。
完成快照停止计时；整轮 turn/end 使圆点变红并保留正文，用户触摸或新活动清红。

## 排障

| 现象 | 检查 |
|---|---|
| 看不到浮窗 | 显示模式、退出状态；无障碍是否已连接，或悬浮窗权限是否已授权 |
| 系统权限页看不到 | 系统保护页面可能主动隐藏应用悬浮窗 |
| 预览不显示 | 关闭模式不预览；检查可用授权路径 |
| 状态未完成 | 检查 AgentBridge/ProgressHub 日志中的 done 与 turn/end |
| 无障碍动作看不到 | 展开卡片，确认动作行有输出 |
| 截图时闪烁 | 检查是否进入整屏截图回退；窗口合成路径优先 |

窗口生命周期、避让规则及开发回归清单见 [OVERLAY.md](OVERLAY.md)。

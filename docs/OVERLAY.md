# 悬浮窗（StatusOverlay）

适用代码：`StatusOverlay.kt`、`ProgressHub.kt`、`overlay_status.xml`。
本文描述当前行为；旧设备与旧版本的取证记录见仓库 `docs/qa/`，不能用作当前实现说明。

## 1. 显示与权限

设置 → 后台进度提示 → 显示方式支持关闭、通知、悬浮窗，默认悬浮窗。
无障碍服务已连接时优先使用 `TYPE_ACCESSIBILITY_OVERLAY`，不需要额外悬浮窗权限；
否则在已授予 `SYSTEM_ALERT_WINDOW` 时使用 `TYPE_APPLICATION_OVERLAY`。
两者均不可用时，进度事件可触发一次权限提示通知。

显示方式关闭或用户退出后，建窗入口拒绝重建。关闭浮窗不影响读屏、点击、OCR、分享与终端。
无障碍服务断开时尝试应用悬浮窗回退；重连时重新选择无障碍窗口。
应用悬浮窗由 applicationContext 持有，避免保留 Activity；系统保护页面仍可能隐藏悬浮窗。

`POST /overlay {"hide":true}` 是显式隐藏入口，后续普通进度不会取消隐藏。
在设置中重新选择悬浮窗、预览或服务重新连接时可以恢复；退出抑制由重新打开 App 解除。

## 2. 形态与内容

| 形态 | 尺寸与内容 | 交互 |
|---|---|---|
| 折叠球 | 36dp 正方形，14dp 居中圆点 | 点击展开，拖动后吸附最近的左/右边缘 |
| 展开卡片 | 宽 240dp，正文滚动区高 92dp；动作行和底部会话/耗时行 | 点左侧圆点收起，正文滚动，空白处可拖动 |

没有长按隐藏，也没有第三档形态。空闲、工作和完成不自动展开/收起。
展开态空闲与工作使用相同正文尺寸；动作行有内容时才显示，因此整张窗口高度并非绝对固定。
会话标题最多 80 字符，实际进度标题取前 60 字符；动作链保留最近 4 条，控件最多显示 2 行。
正文显示最近 600 字符，每次内容变化滚到底部；完整链路仍应在 WebUI 回看。

| 圆点 | 含义 |
|---|---|
| 灰 | 空闲，或用户已确认完成提示 |
| 蓝 | 收到活动进度 |
| 红 | `AgentBridge.onTurnEnd()` 检测到整轮结束 |

完成只改圆点，保留正文。用户触摸或新活动会清红。
`done/error` 快照用于完成标题与停止计时，不自行判定整轮结束。
计时用单调时钟，完成后停止；重建窗口恢复正文、会话、动作和颜色。

## 3. 窗口约束

- 创建时按记忆形态设置初始尺寸，之后由 `applyWindowSize()` 维护；不靠摘挂窗口改外观。
- `overlayDot` 在滚动区外，`overlayScroll` 的 `0dp + weight=1` 必须保留，否则正文宽度为零。
- 普通流式更新只改文本与滚动位置；渲染状态失配时才恢复布局。
- 贴边读取当前屏幕尺寸；形态切换后保持原侧，旋转/分屏后重新约束坐标。
- 移除窗口时注销 DisplayListener、ComponentCallbacks，停止本地 tick 并清掉全部 View 引用。
- 建窗和移除都在主线程；建窗结果不依赖尚未完成的首次绘制。
- 关闭/退出闸门在主线程执行时再次检查，不能只在投递前检查。

### 3.p 避让边界

**禁止路径级避让表。** 普通 `/overlay` 是高频进度更新，不能因为路径或 POST 方法触发隐藏。
旧版把 `/act`、`/overlay` 放进请求级避让后产生过高频闪烁；回归证据见 `qa/flicker-fix-report.md`。

允许的操作避让只有：

1. `dispatchGestureAvoided()` 在注入前计算 stroke 的屏幕边界，与浮窗相交时隐藏；
2. 请求顶层显式 `"avoid":true`，或 `/act` 的 `"hideOverlay":true`。

避让只切 `INVISIBLE/VISIBLE`，不摘挂窗口、不改触摸 flags。
每次避让持有独立凭据，完成时只释放自己的凭据；所有凭据释放后才显示。
重复/迟到回调无效，操作避让的 90 秒兜底只释放自身，不清空截图避让。
相交手势在隐藏后等待 120ms，让系统更新输入窗口再注入；主线程调用采用延迟投递，避免阻塞布局。
手势回调释放避让；异常兜底晚于最后一条 stroke 的结束时间。

## 4. 截图路径

`DshAccessibilityService.screenshotBase64NoFlash()` 优先按窗口截图并合成，再回退到单窗口截图；
API 34 以下或窗口截图不可用时才回退整屏截图和临时隐藏。
窗口合成按浮窗 bounds 排除自身，不按包名排除整个 App。
整屏回退会等待合成、丢弃预热帧；临时隐藏可能闪烁，不能承诺所有设备或回退路径都零闪。
后台图像差分和 OCR 预取不反复隐藏窗口，而是排除浮窗区域的像素/文字。

## 5. 回归检查

- 球点击展开、圆点收起、正文滚动、拖动吸边；长按不隐藏。
- 空闲/工作正文尺寸相同；长正文可滚动，图标静止。
- 整轮结束红点，用户触摸清红，新活动变蓝；完成后的耗时不继续增加。
- 仅无障碍授权、仅应用悬浮窗授权两条路径均可显示。
- 预览可见；关闭后进度不重建；退出后保活不重建；重开 App 可恢复。
- 服务重连/窗口重建恢复内容、位置与形态；不累积显示/配置监听器。
- 重叠截图与手势、长于 1200ms 的手势、重复回调不会提前恢复窗口。
- `bash scripts/acceptance.sh --static`、JVM 单测通过；设备检查需单独记录设备和构建。
